Here are clean notes only for **`ln`**, **`tr`**, and **`nano`**.

## Linux Commands – `ln`, `tr`, `nano`

### 1. `ln` Command – Create Links

The `ln` command is used to create links between files.

There are two types of links:

- Hard Link
- Soft Link / Symbolic Link

### Hard Link

```bash
ln originalfile linkfile
```

Example:

```bash
ln devops.txt hardlink.txt
```

A hard link points to the same inode as the original file.

Check inode numbers:

```bash
ls -li
```

Example:

```text
12345 -rw-r--r-- 2 user user 100 devops.txt
12345 -rw-r--r-- 2 user user 100 hardlink.txt
```

Both files have the **same inode number**.

Even if the original file is deleted:

```bash
rm devops.txt
```

the hard link still works:

```bash
cat hardlink.txt
```

### Soft Link / Symbolic Link

```bash
ln -s originalfile linkfile
```

Example:

```bash
ln -s devops.txt softlink.txt
```

Check:

```bash
ls -l
```

Output may look like:

```text
lrwxrwxrwx 1 user user 10 softlink.txt -> devops.txt
```

The first character is:

```text
l
```

which indicates a symbolic link.

If the original file is deleted:

```bash
rm devops.txt
```

the symbolic link becomes broken.

### Hard Link vs Soft Link

| Feature | Hard Link | Soft Link |
|---|---|---|
| Inode | Same | Different |
| Original deleted | Still works | Link breaks |
| Files | Yes | Yes |
| Directories | Normally no | Yes |
| Cross filesystem | No | Yes |
| `ls -l` | Regular file | Starts with `l` |

### Common Examples

Create hard link:

```bash
ln file1.txt file2.txt
```

Create symbolic link:

```bash
ln -s file1.txt file2.txt
```

Create symbolic link for directory:

```bash
ln -s /var/log /home/user/logs
```

### Use Cases

- Create multiple names for the same file.
- Create shortcuts to files and directories.
- Point applications to configuration files.
- Access frequently used directories easily.

## 2. `tr` Command – Translate Characters

The `tr` command means **translate**.

It is used to:

- Convert characters
- Replace characters
- Delete characters
- Normalize text

`tr` reads input from **standard input (stdin)**.

### Convert Lowercase to Uppercase

```bash
echo "hello devops" | tr 'a-z' 'A-Z'
```

Output:

```text
HELLO DEVOPS
```

Using a file:

```bash
cat demo.txt | tr 'a-z' 'A-Z'
```

Better form:

```bash
tr 'a-z' 'A-Z' < demo.txt
```

### Convert Uppercase to Lowercase

```bash
echo "HELLO DEVOPS" | tr 'A-Z' 'a-z'
```

Output:

```text
hello devops
```

### Replace Characters

```bash
echo "devops-linux" | tr '-' '_'
```

Output:

```text
devops_linux
```

Another example:

```bash
echo "10:20:30" | tr ':' '-'
```

Output:

```text
10-20-30
```

### Delete Characters

Use:

```bash
tr -d
```

Example:

```bash
echo "devops123" | tr -d '0-9'
```

Output:

```text
devops
```

Delete spaces:

```bash
echo "hello devops linux" | tr -d ' '
```

Output:

```text
hellodevopslinux
```

### Remove Repeated Characters

Use:

```bash
tr -s
```

Example:

```bash
echo "hello     devops" | tr -s ' '
```

Output:

```text
hello devops
```

### Common Examples

```bash
tr 'a-z' 'A-Z' < file.txt
```

Lowercase → uppercase.

```bash
tr 'A-Z' 'a-z' < file.txt
```

Uppercase → lowercase.

```bash
tr -d '0-9' < file.txt
```

Delete numbers.

```bash
tr -s ' ' < file.txt
```

Remove repeated spaces.

### Use Cases

- Convert log output to uppercase/lowercase.
- Clean unwanted characters from files.
- Remove extra spaces.
- Format shell-script output.
- Normalize text before processing it with `grep`, `awk`, or `sed`.

## 3. `nano` Editor

`nano` is a simple and beginner-friendly command-line text editor.

### Open/Create a File

```bash
nano demo.txt
```

If `demo.txt` exists, it opens the file.

If it does not exist, nano creates it when you save.

### Install Nano

Amazon Linux / RHEL:

```bash
sudo yum install nano -y
```

Newer systems may use:

```bash
sudo dnf install nano -y
```

Ubuntu/Debian:

```bash
sudo apt install nano -y
```

### Important Nano Shortcuts

In nano, the `^` symbol means **Ctrl**.

| Command | Purpose |
|---|---|
| `Ctrl + O` | Save file |
| `Ctrl + X` | Exit |
| `Ctrl + W` | Search |
| `Ctrl + K` | Cut line |
| `Ctrl + U` | Paste |
| `Ctrl + G` | Help |

### Save a File

After editing:

```text
Ctrl + O
```

Nano asks for the filename.

Press:

```text
Enter
```

Then exit:

```text
Ctrl + X
```

### Exit Without Saving

Press:

```text
Ctrl + X
```

When asked:

```text
Save modified buffer?
```

Press:

```text
N
```

### Search Inside a File

Press:

```text
Ctrl + W
```

Enter the text:

```text
error
```

Press:

```text
Enter
```

### Example

Create a shell script:

```bash
nano test.sh
```

Add:

```bash
#!/bin/bash

echo "Welcome to Linux"
```

Save:

```text
Ctrl + O
Enter
```

Exit:

```text
Ctrl + X
```

Give execute permission:

```bash
chmod +x test.sh
```

Run:

```bash
./test.sh
```

### Use Cases

- Edit configuration files.
- Create shell scripts.
- Modify application files.
- Quickly edit files on Linux servers.
- Useful for beginners who find `vi` difficult.
